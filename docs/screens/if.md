### 1.5 同期

クラウド有効かつログイン中。未ログインでは同期しない（記録もしない）。記録の正は端末（IndexedDB）。クラウドは同期先。`GET /records` に無いことは削除理由にしない。

未送信の生存件は、ログイン済みでオフライン中に付けたもの（および同期に失敗したもの）。未ログインで記録が付くことはない。

| 項目 | 内容 |
|------|------|
| 取り込み | ログイン直後、履歴を開いたとき、オンライン復帰時に `GET /records`（前回同期時刻があれば `?since=`） |
| 新端末 | IndexedDB が空。生存件を取り込み、削除ログの ID は無視してよい（無いものは消さない） |
| ユーザー削除 | いつでも可（オフライン含む）。端末からすぐ消し、消した ID を端末の削除ログに残す。オンラインならすぐ `DELETE /records/{id}` |
| 他端末の削除 | 同期中だけ適用する。根拠は応答の `deleted`（クラウドの削除ログ）だけ |
| 衝突 | 削除が編集に勝つ。同じ `id` を二台で編集したときは、未送信の端末変更は GET で上書きしない。両方未送信なら後に成功した POST がクラウドの正 |

同期の順:

1. 端末の未送信削除を `DELETE /records/{id}`
2. `GET /records`（`deleted` 込み）
3. `deleted` の ID を端末から消す（未送信の編集があっても消す。POST しない）
4. 生存件を取り込む。端末に無くクラウドにある ID は追加。両方にある ID は、端末が未送信なら端末を残す。未送信でなければクラウドで更新
5. 未送信の生存件を `POST /records`（削除ログにある ID は送らない）
6. 成功した GET の端末時刻を次回の `since` にする（重複適用は冪等）

`GET` に載らないローカル件は消さない（未送信の新規を含む）。

詳細は [API IF API-02〜04](../api/if.md#api-02-get-records) / [API 設計 記録](../api/design/records.md)。

## 3. 公開・認証

### SCR-01 ランディング

| 項目 | 内容 |
|------|------|
| 認証 | 公開。クラウド有効かつ未ログインの `/` |
| 目的 | サービス紹介と登録誘導 |

| 操作 | 遷移 |

### SCR-02 / SCR-03 / SCR-04 ログイン・登録・確認

同一ルート。`?mode=signup` で登録。確認コード成功後はログイン画面へ戻る（自動ログインしない）。

**パスワード方針（Cognito）:** 8 文字以上、英小文字と数字必須。記号・大文字は不要。

#### ログイン（SCR-02）

| 項目 | 種別 | 必須 | 制約 |
|------|------|------|------|
| メールアドレス | email | はい | trim |
| パスワード | password | はい | 8 文字以上 |

| 操作 | 結果 |
|------|------|
| ログイン | Cognito signIn → `/`（SCR-06）。続けて [1.5 同期](#15-同期) |
| パスワードを忘れた | SCR-05（state にメール） |
| アカウントを作成 | SCR-03 |
| 戻る | `/` |

#### 新規登録（SCR-03）

ログイン項目に加え:

| 項目 | 種別 | 必須 | 制約 |
|------|------|------|------|
| 規約・プライバシー同意 | checkbox | はい | 未チェックだと「登録する」不可 |

| 操作 | 結果 |
|------|------|
| 登録する | Cognito signUp → 情報「確認コードをメールで送信しました」→ SCR-04 |
| 利用規約 / プライバシー | 別タブで SCR-19 / SCR-18 |
| ログインに戻る | SCR-02 |

未同意で送信: 「利用規約とプライバシーポリシーへの同意が必要です」。

#### 確認コード（SCR-04）

| 項目 | 種別 | 必須 |
|------|------|------|
| メールアドレス | 表示（disabled） | — |
| 確認コード | text / numeric | はい |

| 操作 | 結果 |
|------|------|
| 確認する | confirmSignUp → 「登録が完了しました。ログインしてください」→ SCR-02 |

### SCR-05 パスワード再設定

## 4. 記録・履歴

### SCR-06 記録

| 項目 | 内容 |
|------|------|
| 認証 | ログイン後、またはクラウド無効 |
| 目的 | ワンタップで条件付き釣果を保存 |

#### 入力

| 項目 | 種別 | 必須 | 制約 |
|------|------|------|------|
| 写真 | COM-03 | いいえ | |
| 魚種 | COM-04 | いいえ | 保存時に正規名 |
| 体長 | number | いいえ | 単位はマイページ。0 以上。空は null |
| 重さ | number | いいえ | 同上 |
| タックル | COM-05（開閉） | いいえ | |
| 次回もこのタックルを使う | checkbox | — | オンなら記録後も下書きを残す |

体長・重さの不正: 「体長は 0 以上の数値で入力してください」「重さは 0 以上の数値で入力してください」。

#### タックルパネル操作

| 操作 | 結果 |
|------|------|
| タックル入力を開く / 閉じる | パネル開閉。閉時に入力ありならセット名を表示 |
| マイタックルを使う | 端末保存セットから選択。メッセージ「「{name}」を適用しました」 |
| マイタックルに保存 | 内容必須。名前空なら「無題」。成功「マイタックルに保存しました」 |
| 入力をクリア | 空にする |

マイタックル空: 「マイタックルがまだありません」。内容なし保存: 「タックルの内容を入力してください」。

#### 記録する

GPS 失敗でも保存する。天気・場所名・潮位の失敗は null（記録は止めない）。オフライン時は端末のみ。

進捗（COM 記録進捗）:

| ステップ | ラベル | 状態 |
|----------|--------|------|
| geo | 位置 | 取得中 / 完了 / 失敗 |
| weather | 天気・気温 | 同上。GPS 失敗時はスキップ |
| tide | 潮位 | 同上 |
| save | 保存 | IndexedDB + クラウド POST |
| photo | 写真 | 写真なしはスキップ。presign → S3 PUT |

保存後: 魚種・体長・重さ・写真をクリア。タックルは「次回も使う」がオンなら残す。

| 操作 | 遷移 |
|------|------|
| 記録する | 進捗 → 保存サマリー |
| 続けて記録 | フォーム先頭へスクロール |
| 履歴 / 履歴を見る | SCR-07 |

保存サマリー表示: 日時、魚種・サイズ、写真、`RecordValueList`、警告リスト。

呼び出す API（クラウド有効時）: `GET /weather/current` `GET /place/current` `GET /tide/current` `POST /photos/presign` `POST /records`。同期は [1.5](#15-同期)（`GET /records` と未送信の POST / DELETE）。

### SCR-07 履歴

| 項目 | 内容 |
|------|------|
| 認証 | 要ログイン |
| クエリ | `?from=` `?to=`（YYYY-MM-DD）。旧 `?date=` は単日 |

| 表示 | 内容 |
|------|------|
| カレンダー | 記録がある日をマーク。開始日・終了日タップで期間 |
| 期間ラベル | 「{開始}〜{終了}（N件）」+ 期間を解除 |
| 地図 | フィルタ後のピン。同一地点はグループ |
| 日ごとカード | 時刻・魚種・サイズ・場所・天気一行 + サムネ |

| 操作 | 結果 |
|------|------|
| 地図ピン | SCR-08。前後対象はその地点の記録 |
| カードタップ | SCR-08。前後対象はフィルタ後の全件 |
| マイ魚種図鑑 | SCR-12 |

空状態: 「まだ記録がありません」「この期間の記録はありません」。削除後トースト「削除しました」（約 2.5 秒）。

### SCR-08 記録詳細シート

履歴・魚種詳細のオーバーレイ。ルートではない。

| 操作 | 結果 |
|------|------|
| 左右スワイプ / 前後 | 前後の記録 |
| 下スワイプ / 閉じる | 親画面へ |
| 写真タップ | 拡大表示。閉じる / 背景タップ / Escape で戻る |
| 編集 | SCR-09 |
| 削除 | 確認「この記録を削除しますか？」→ 削除する / やめる |
| 画像を保存 | 端末へ保存 |

表示: 日付・時刻、写真（大）、`RecordValueList`（場所・天気・気温・風速・太陽・潮位・潮種・潮位変化、および魚種・サイズ・タックル）。`recordedAt` / `location` を手動変更した項目は「（編集済み）」。場所は地図リンク。座標ありかつクラウド時は、記録日の潮位グラフ（釣れた時刻の印。記録日が当日ならいまの印も。満潮・干潮の時刻）。取得失敗・オフライン・座標なしは出さない。

削除は端末からすぐ消す。オンラインなら `DELETE /records/{id}`。失敗・オフラインなら端末の削除ログに残し、次回同期で送る（[1.5](#15-同期)）。

### SCR-09 記録編集

シート内フォーム。座標または時刻（分）が変わると潮位・場所名・日出没を取り直す。**天気は再取得しない**（記録時の値を維持）。

| 項目 | 種別 | 必須 | 内容 |
|------|------|------|------|
| 写真 | COM-03 | いいえ | 既存サムネ + 差し替え |
| 魚種 | COM-04 | いいえ | |
| 体長 / 重さ | number | いいえ | SCR-06 と同じ |
| タックル | COM-05 | いいえ | |
| 記録日時 | datetime-local | はい | 空は「記録日時を入力してください」 |
| 場所 | 地図ピッカー | いいえ | ドラッグ・タップで指定。「現在地を使う」 |

自動取得欄（編集不可）: 場所名・天気・気温・風速・太陽・潮位。更新中は「天気・潮位・場所名を更新中…」。

| 操作 | 結果 |
|------|------|
| 保存する | IndexedDB + `POST /records`（同一 id は更新）。閲覧へ戻る |
| キャンセル | 破棄して閲覧へ |

座標変更は `editedFields` に `location`、時刻変更は `recordedAt` を付ける。

| 魚種カード | SCR-13 |
| 戻る | SCR-10 |

カード表示: 代表画像（写真付き記録のうち最大サイズ。なければプレースホルダ）、魚種、匹数、最大サイズ、最大重量、最大釣果日（日付と匹数）。空: 「魚種付きの記録がまだありません」。

### SCR-13 魚種詳細

パス `/mypage/encyclopedia/:species`（URL エンコード）。クエリ `?record=` で該当カード、`?date=` でその日へスクロール。

| 表示 | 内容 |
|------|------|
| 集計 | 魚種、匹数、最大サイズ、最大重量、最大釣果日 |
| 日付セクション | その魚種の記録カード |

| 操作 | 結果 |
|------|------|
| 最大サイズ / 最大重量 | `?record=` で該当カードへ |
| 最大釣果日 | `?date=` でその日へ |
| 記録カード | SCR-08（前後対象はその魚種の全件） |
| 戻る | SCR-12 |

記録なし: 「この魚種の記録はありません」。

### SCR-14 メールアドレス変更

クラウド必須。2 ステップ。完了後も同画面。

| 項目 | 必須 | 制約 |
|------|------|------|
| 新しいメールアドレス | はい | 現在と同一は「現在と同じメールアドレスです」 |
| 確認コード | はい | ステップ2 |

操作: 確認コードを送信する → 変更を確定する。成功「メールアドレスを変更しました」。Cognito UpdateUserAttributes / VerifyUserAttribute。

### SCR-15 パスワード変更

クラウド必須。

| 項目 | 必須 | 制約 |
|------|------|------|
| 現在のパスワード | はい | |
| 新しいパスワード | はい | 8 文字以上 |
| 新しいパスワード（確認） | はい | 一致 |

成功「パスワードを変更しました」（入力クリア、同画面）。Cognito changePassword。

### SCR-16 退会

クラウド必須。

| 項目 | 必須 |
|------|------|
| 同意チェック | はい（未チェックは送信不可） |

注意書き: 即ログイン不可、クラウド記録・写真は 7 日以内削除、端末データも削除。

| 操作 | 結果 |
|------|------|
| 退会する | `DELETE /account` → 端末データ消去 → signOut → `/login` |
| 戻る | SCR-10 |

未チェック送信: 「内容を確認のうえ、チェックを入れてください」。
